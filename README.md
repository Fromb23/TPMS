> A web-based platform that streamlines and manages the entire Teaching Practice (TP) lifecycle for Kenyan universities — including students, lecturers, and placement schools.

## 🧠 About the System

TPMS enables student-teachers to:

- View and agree to TP Guidelines
- Submit lesson plans
- Receive lecturer supervision feedback
- Track their teaching practice progress
- Communicate via notifications and system alerts

It enables university lecturers and admins to:

- Assign supervisors to students
- Track student placement in schools
- View submitted lesson plans and grade them
- Communicate updates through the notification system

---

## ✨ Key Features

- 📜 **TP Guidelines Page**  
  A dedicated, mandatory agreement page with 15 comprehensive rules students must agree to before continuing.

- 🔐 **Role-Based Access**  
  Students, Lecturers, and Admins access different parts of the system using protected routes.

- 📬 **Notification System**  
  Real-time UI notifications with red alert indicators, shown in the top-right header for each logged-in user.

- 🧑‍🏫 **Supervisor Assignment**  
  Admins assign supervisors to student-teachers and track visits.

- 📦 **Lesson Plan Management**  
  Students submit plans; lecturers review and approve.

- 💼 **TP Placement Tracking**  
  System stores each student’s school placement, timelines, and evaluation status.
